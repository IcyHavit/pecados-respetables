# Pecados respetables — libro digital

Proyecto estático listo para GitHub Pages.

## Publicarlo

1. Sube `index.html`, la carpeta `chapters` y el archivo `.nojekyll` a la raíz de tu repositorio.
2. En GitHub, abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main`, la carpeta `/ (root)` y pulsa **Save**.

El libro funciona sin instalar dependencias. Incluye navegación por capítulos, zoom, ajuste de texto, pantalla completa, lectura en voz alta, teclado y gestos táctiles.
